Scaffold is in. We need your real Bee data next.

Run these on the Mac that is logged into Bee (Watch + iPhone, Developer Mode on). Paste the output back into this chat. Do not commit real transcripts — they go in fixtures/real/, which is gitignored.

  1. 1. Confirm the CLI

    npm install -g @beeai/cli
bee version
bee login          # skip if bee status already shows you
bee status
bee ping
bee me --json

  2. 2. Capture a sync snapshot

    mkdir -p fixtures/real
bee sync --output fixtures/real/sync --recent-days 14
bee conversations list --json --limit 50 > fixtures/real/conversations.json
bee todos list --json > fixtures/real/todos.json
bee facts list --json > fixtures/real/facts.json
bee now --json > fixtures/real/now.json

  3. 3. Pull a couple of transcripts

    Pick two conversation ids from the list (engineering talk beats small talk).

    bee conversations transcript  --json > fixtures/real/transcript-.json
bee conversations get  --json > fixtures/real/conversation-.json
bee conversations related  --json > fixtures/real/related-.json

  4. 4. Sample the live stream (~45s)

    macOS has no timeout(1) by default. This works:

    bee stream --json --types new-conversation,update-conversation,update-conversation-summary,new-utterance,todo-created,todo-updated > fixtures/real/stream.jsonl &
STREAM_PID=$!
sleep 45
kill $STREAM_PID
wait $STREAM_PID 2>/dev/null
wc -l fixtures/real/stream.jsonl

  5. 5. Paste back

    Paste bee status, bee me --json (redact email if you want), line counts, and one redacted transcript. That locks the payload shapes for Phase 1. Full capture script: scripts/capture-fixtures.sh.
